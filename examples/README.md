# Example workouts

The workouts shown on [portableworkout.org](https://portableworkout.org/#examples), from yoga and Pilates to strength, boxing, running and group classes.

`examples.json` lists them in the order the website shows them, each with its discipline and the group the website filters it under. `npm run check` checks that every example validates and plays, and that `examples.json` lists every file here.
