Portable Workout Format

PWF is an open JSON format for describing, sharing and running workouts across apps. This demo builds a workout, saves it as a .pwf.json file and plays it back.

The demo covers a small part of PWF on purpose. The player follows the same timing rules as the conformance suite.

Build a workout

Sections, rounds, timed or rep-based exercises and rests. Export a .pwf.json file or try it straight away.

Play a workout

Open any PWF file, or a shared link, and follow it with a timer, round counts and what's up next.
